## ข้อตกลง
- ต้องมีเกมของแท้ ม็อดนี้มีแค่คำแปล ไม่มีไฟล์ของเกม
- ไม่มีส่วนเกี่ยวข้องกับผู้พัฒนา ผู้จัดจำหน่าย หรือเจ้าของลิขสิทธิ์ของเกมใด ๆ
- แจกฟรี ห้ามนำไปขายหรืออัปโหลดใหม่โดยไม่ให้เครดิต
- หากเจ้าของลิขสิทธิ์ต้องการให้นำออก ติดต่อผ่าน Issue จะนำออกทันที
