ประเภทปัญหา *

มีภาพหน้าจอ? กด "ส่งผ่าน GitHub" แล้วลากรูปใส่ช่องข้อความในหน้าถัดไปได้เลย

ตัวอย่างรายงาน
กรอกฟอร์มด้านบนแล้วรายงานจะขึ้นตรงนี้
  • อย่าใส่ข้อมูลส่วนตัว เช่น เบอร์โทร อีเมล หรือ Steam ID (ไฟล์ log ของ BepInEx อาจมี Steam ID ให้ลบออกก่อนแนบ)
  • หน้า Issues บน GitHub เป็นสาธารณะ ทุกคนอ่านได้

"ส่งผ่าน GitHub" ต้องมีบัญชี GitHub (สมัครฟรี) ถ้าไม่มี กด "คัดลอกรายงาน" แล้วส่งทางช่องทางอื่นได้
